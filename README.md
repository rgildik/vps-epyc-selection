## EPYC 对 VPS 使用有什么意义？

AMD EPYC 是服务器处理器系列。对 VPS 用户来说，换用更新的宿主机平台可能有利于计算和存储性能，但你租到的是虚拟机，不是整颗物理 CPU。实际表现还取决于分配给实例的 vCPU、宿主机负载、应用是否能并行，以及磁盘和网络是否成为瓶颈。

可以按工作类型判断：

- **轻量网站、个人博客**：内存、磁盘读写和线路稳定性往往同样重要。CPU 更新有帮助，但不必只因 EPYC 三个字就买更高档套餐。
- **数据库、动态网站、构建任务**：CPU 和存储响应都可能影响体验，NVMe 存储对频繁读写更有参考价值。
- **多进程服务或容器**：要同时看 vCPU、内存余量和流量限制。处理器型号不能代替资源规格。
- **面向中国大陆访问的服务**：机房线路与运营商路由应单独评估。EPYC 是硬件信息，不代表线路自动变好。

搬瓦工官网把 KVM VPS 描述为自管理服务，并提供 KiwiVM 面板管理、重装系统、快照、机房迁移等功能；这些功能属于 VPS 管理便利性，和 CPU 型号是两回事。

## 选购时，先看机房，再看配置

如果 EPYC 是硬性要求，建议按这个顺序确认：

1. **确认机房代码。** 先检查订单页面是否能选 USNY_6、USNY_8、HK3、HK8 或 USCA_9 等已公告地点。
2. **确认新旧实例状态。** 已有用户登录 KiwiVM，查看是否出现硬件升级选项。官方公告提到符合条件的旧实例可以在那里升级。
3. **核对套餐资源。** 对照 RAM、存储容量、流量和 CPU 配额，避免只按处理器系列做决定。
4. **按访问人群判断线路。** 如果用户主要在中国大陆，线路和运营商表现要与 CPU 分开考虑。
5. **关注最终结账信息。** 确认周期、币种、续费金额和可用机房后再付款。公开展示的起售价不一定代表每个位置都可选。

特别是跨机房迁移，不能只凭“支持迁移”就假定任意套餐都能搬到任意区域。要以 KiwiVM 或订单页面实际提供的目标机房为准。

## 怎么确认 VPS 实际运行在哪种 CPU 上？

购买后可以通过 SSH 登录服务器，查看虚拟机向操作系统暴露的处理器信息。例如 Linux 系统可运行：

bash
lscpu


或查看：

bash
cat /proc/cpuinfo


输出通常能看到 CPU 型号字符串，但虚拟化环境可能会隐藏或调整部分信息。若结果没有清楚显示具体型号，可以在 KiwiVM 检查节点或升级状态，或向服务商提交工单确认。不要把第三方测评中某台机器的跑分，当作你所购实例的性能保证；共享宿主机、配置和测试负载都可能不同。

## 常见问题

### 搬瓦工所有 VPS 都是 AMD EPYC 吗？

不是。官方公告针对具体机房发布，官网通用 KVM 套餐页面也仍展示 Intel Xeon 规格。应按机房和订单页面确认，不能把个别节点的硬件推广到全部产品。

### 已有用户能免费升级吗？

部分公告说明旧 VPS 可以登录 KiwiVM 查看免费升级选项；是否适用于你的实例，需要以控制面板实际显示为准。不要仅根据机房名称推断已经自动升级。

### 搬瓦工有 EPYC 专属套餐吗？

从当前可读取的官网公开套餐页面，无法确认存在单独按 EPYC 命名、且公开列出完整价格和配置的套餐系列。官方新闻说明了特定机房部署 AMD EPYC，但套餐与硬件节点的对应关系应以购买时的机房选项和后台实例信息为准。

### EPYC 一定比旧平台快很多吗？

不能仅凭处理器系列给出统一幅度。虚拟机获得的 CPU 资源、宿主机竞争、程序类型和存储响应都会影响结果。若服务负载稳定，最好用自己的应用做压力测试，再决定是否升级配置。

### 现在有确定可用的优惠码吗？

本次核验到的官方页面展示了套餐价格和硬件公告，但没有找到能够确认当前有效的优惠码或促销条件。因此这里不列未经确认的折扣码；结账页面显示的实际价格应作为付款前依据。
